## 四种证据形态逐字模板

「凭什么算爆款」字段只允许以下四种形态。形态 id 由 `judge_evidence.compose_evidence`
按固定顺序短路选出（顺序即优先级）：

| 序 | 条件 | 形态 id | 模板 |
|---|---|---|---|
| 1 | A 档且有榜位 | rank | 在某榜单名（榜单名「第 N」位） |
| 2 | 指标缺失或 UNPARSABLE | none | 未获取 |
| 3 | 无基线 | rank / absolute | 榜单形态 / 点赞 1.2万 |
| 4 | 倍数通过且被评指标为 EXACT | relative | 点赞 8.7万，该账号近 n 条点赞中位数 中位数（≥3 倍，判定为爆款） |
| 5 | A / B 档 | rank / absolute | 榜单形态 / 点赞 1.2万 |
| 6 | 其余（C 档） | none | 未获取 |

绝对数值形态的拼装规则：

- 按「播放 → 点赞 → 收藏 → 评论」固定序列出各指标**原文**
- 参与求和的项不加任何标记
- 被剔除的 VERBATIM 项在证据末尾注明（例如 `点赞 约50万`）
- 若判定所用指标不是播放（平台不公开播放量），写明「判定所用指标：点赞」

无基线时证据文本**不得**出现「中位数」或「倍」字样。

渲染层硬约束（`rank_render.post_assertions` 强制，命中即 exit 2）：

- **禁止自造修饰词**：不得出现「大约 / 预计 / 左右」等我们自己加的词
- **原文修饰词放行**：页面原文里本来存在的「约」与加号属照抄，不违规。
  实现方式是把全部原文从文本里剔除后再扫黑名单，因此照抄的「约50万」不会被误判
- **「未获取」不得被替换**：`暂无` 与 `null` 与 `0` 与 `未知` 等一律 exit 2（完整黑名单见上表）
- **末尾无总结建议**：不得出现总结 / 规律 / 建议 / 下一步小节，也不得出现占比统计行

## 平台字段取值顺序

1. URL 的 host 精确命中归属表，取该平台（确定性）
2. 否则取喂料上下文（`--platform` 回显确认过的值），取该平台
3. 两者都推断不出，写「未获取」，**不猜**

短链（如 url.cn / t.cn / v.kuaishou.com）无法归属到四平台，按第 3 条填「未获取」，
但**条目照常输出**——平台字段拿不准不等于条目无效。

## 地址准入判据（唯一硬门槛）

```text
地址有效  <=>  协议属于 http 与 https
          且 溯源核验通过（url.raw 是喂料原文子串）
          且 query 不含访问凭据型参数名
          且 短链与长链一视同仁
```

域名**不在**准入判据里。明确禁止：展开短链跳转、猜真实域名、把短链改写成任何
自生成 URL（含补参数 / 换 host / 拼分享参数）、用展开后的域名替换输出的短链原文。

输出即喂料或读到的原链接字符串，这本身就是短链。
